This is the code for a sound reproduction simple tool for the Week 2 assignment at the Web Tools for Creative Work class. 
Most of this work was inspired and done by following the MDN Documentation in Web Audio API and HTML and css.

Those you can find in the following links.
https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/input/range
https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Colors/Applying_color
https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API/Using_Web_Audio_API
https://developer.mozilla.org/en-US/docs/Web/API/AudioBufferSourceNode/playbackRate

I still would love to learn more about styling in general and the file management within web pages, in audio and video for further manipulation and analysis.
